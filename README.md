# منصة تطوير مكتبات أكاديمية الفلاح 2026

## الملفات
- index.html: الواجهة الرئيسية.
- evaluation/index.html: نظام تقييم المكتبات.
- schedule/index.html: جدول الأعمال اليومي والمتابعة.
- reports/index.html: المقارنة النهائية والتقرير الشامل.
- schools/*/index.html: صفحة خاصة لكل مكتبة من المدارس الست.

## الرفع على GitHub Pages
ارفع محتويات هذا المجلد إلى Repository، ثم فعّل Pages من Settings > Pages > Deploy from branch.

## مهم
البيانات تحفظ في متصفح المستخدم عبر localStorage. لنقل البيانات بين الأجهزة استخدم تصدير JSON ثم استيراد JSON من صفحة التقييم.
